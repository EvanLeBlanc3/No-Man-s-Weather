# No Man's Weather 🌌☔

Pixel-art, space-explorer weather app for iPhone (installable web app).

## Install / update on GitHub
1. Unzip this file and upload **everything inside it** to your GitHub repo (replace existing files).
2. Settings → Pages → Branch: main, folder: / (root) → Save.
3. On iPhone, open your GitHub Pages link in Safari → Share → Add to Home Screen.
4. After updating, fully close the app and reopen it (twice if needed).

## Data
Open-Meteo (forecast + air quality), National Weather Service (US alerts), BigDataCloud (city names).
