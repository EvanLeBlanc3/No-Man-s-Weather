# No Man's Weather 🌌☔

A pixel-art space-explorer weather app for iPhone. It uses your location, draws the weather as an animated alien planet, and runs as an installable web app.

## Install on your iPhone (step by step)

### Part 1: Put it on GitHub
1. Go to **github.com** and sign in.
2. Tap **+** (top right) → **New repository**.
3. Name it `no-mans-weather`, set it to **Public**, and tap **Create repository**.
4. Tap **uploading an existing file**.
5. Unzip `no-mans-weather.zip` on your computer, open the folder, and drag **everything inside it** into the upload box. That means `index.html`, `app.js`, `style.css`, `sw.js`, `manifest.json`, `README.md`, and the whole `icons` folder.
   - ⚠️ Drag the *contents* of the folder, not the folder itself. `index.html` needs to be at the top level of the repo.
6. Scroll down and tap **Commit changes**.

### Part 2: Turn on GitHub Pages
1. In the repo, tap **Settings** → **Pages** (left sidebar).
2. Under **Branch**, choose **main** and **/ (root)**, then tap **Save**.
3. Wait 1–2 minutes and refresh. GitHub will show your link:
   `https://YOUR-USERNAME.github.io/no-mans-weather/`

### Part 3: Add it to your Home Screen
1. Open that link in **Safari** on your iPhone. (It has to be Safari.)
2. Tap **▶ INITIALIZE**, then tap **Allow** when it asks for your location.
3. Tap the **Share** button (the square with the up arrow) → **Add to Home Screen** → **Add**.
4. Open it from the new Home Screen icon. 🚀

## Good to know
- **Location:** If you tapped "Don't Allow", go to iPhone **Settings → Privacy & Security → Location Services → Safari Websites** and set it to *While Using*. You can also type a city into **Warp to a city** under Ship Systems.
- **Offline:** After the first launch, the app itself works offline. Without a signal it shows your **last saved scan**, and the status pill reads **OFFLINE**. You need a connection to get new weather.
- **Auto refresh:** It rescans every 60 seconds while it's open. You can turn this off under **Ship Systems**. Tap **⟳ SCAN** any time to refresh by hand.
- **Sound:** iPhones only allow sound after you tap something, which is why there's an **INITIALIZE** button. If you hear nothing, check that the ringer switch isn't on silent.
- **Portrait lock:** The app stays in portrait mode. If you turn the phone sideways, it will ask you to turn it back.
- **Updating later:** Upload the changed files to GitHub again. If the app still shows the old version, close it and reopen it twice. To force an update, change `nmw-v1` to `nmw-v2` in `sw.js`.

## Data sources
- Forecasts: [Open-Meteo](https://open-meteo.com) (free, no API key)
- Air quality: Open-Meteo Air Quality API
- Severe weather alerts (US only): National Weather Service (api.weather.gov)
- City names: BigDataCloud reverse geocoding
